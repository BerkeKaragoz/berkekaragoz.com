# British English pronunciation data

The dictionary chunks in this directory are generated from Britfone 100.0.1.

- Project: https://github.com/JoseLlarena/britfone
- Package: https://www.npmjs.com/package/britfone
- Licence: MIT (see `LICENSE.txt`)

The build removes spacing between phonemes and presents a teaching-friendly
British notation (`r`, `e`, `ʌ`, `ɡ`). Stress marks are moved from the source
vowel-nucleus position to the start of the syllable using English onset rules.
The build does not alter word coverage or invent pronunciations.
